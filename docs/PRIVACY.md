# Privacy

EduSchedule starts with no configured school. After first-time setup, it connects directly to the public EduPage school you selected for timetable data and to GitHub for app update checks. These services receive ordinary request metadata, including your IP address and user agent. No timetable is sent to an EduSchedule server; there is no server or analytics SDK.

Timetables, chosen class, group visibility and preferences are stored in the app's private device storage. Android app backup is disabled. Clear storage or uninstall to remove them. Exports are saved only to a destination you choose and may contain publicly published teacher names and room/class information. Calendar insertion opens your calendar editor; saving an event may synchronize it using that calendar account's settings.

Permissions: Internet and network state for refresh, optional notifications for class-start reminders, timetable changes and app updates. No contacts, location, calendar reading, broad file access or package installation permission is requested.
